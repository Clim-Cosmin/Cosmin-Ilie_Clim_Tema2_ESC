# Pagină Web cu Curiozități despre Pisici

O aplicație web simplă care afișează curiozități aleatorii despre pisici prin conectarea la Cat Facts API.

## Caracteristici

- Obține curiozități aleatorii despre pisici prin apăsarea butonului
- Afișează un contor pentru numărul de curiozități afișate
- Permite aprecierea (like) curiozităților preferate
- Păstrează un istoric cu ultimele 10 curiozități afișate
- Permite copierea curiozităților în clipboard
- Design responsive care funcționează pe dispozitive mobile
- Persistență a datelor (istoric și like-uri) folosind localStorage
- Animări și efecte vizuale atractive

## Tehnologii utilizate

- HTML5
- CSS3 (cu Flexbox și Grid)
- JavaScript (ES6+)
- Cat Facts API (https://catfact.ninja/)

## Cum să rulezi aplicația

1. Descarcă toate fișierele într-un folder
2. Deschide fișierul `index.html` în browser
3. Apasă butonul "Află o curiozitate!" pentru a obține o curiozitate despre pisici

Sau, poți accesa direct aplicația online dacă este hostată pe un server web.
